# 🏛 자산 문명 (Asset Civilization)

내 자산이 문명이라면 지금 몇 단계일까? — **《문명》 스타일 2.5D 헥사곤 디오라마**로 내 자산과 다우지수·S&P 500·나스닥 100·목표 연이율을 나란히 비교하는 정적 웹앱입니다.

## 무엇을 보여주나

- **18단계 문명 진화**: 원시 벌판의 모닥불(1단계)에서 성간 스타포트(18단계)까지, 같은 섬이 자산 규모에 따라 성장합니다.
- **2.5D 헥사곤 디오라마**: Canvas 2D로 그린 육각 타일 지형, 입체 음영, 바다·물결 반사, 구름·새·사슴·말·기차·비행기·로켓·우주선이 계속 움직입니다.
- **환율 반영 비교**: 입금일마다 원화를 그날 환율로 달러로 바꿔 지수에 넣었다고 가정하고, 오늘 지수 × 오늘 환율로 원화 환산합니다.
- **원화 ↔ 달러 스위치**, **미래 타임머신 슬라이더(0~10년)**, **18단계 문명 도감**.

## 기본값 (2026-11 기준 실제 수치)

| 항목 | 값 |

모든 값은 **⚙ 설정**에서 고칠 수 있고 `localStorage`에 저장됩니다. 삼성증권 입출금 CSV 붙여넣기도 지원합니다.

## 데이터

`data/market_history.json` — Yahoo Finance chart API에서 내려받은 `^DJI` · `^GSPC` · `^NDX` · `KRW=X`의 **2020-01-01 이후 일별 종가**(약 160KB). 브라우저에서는 파일을 읽기만 하므로 CORS·레이트리밋 문제 없이 즉시 계산됩니다. 네트워크가 막히면 앱 내부 스냅샷으로 자동 폴백합니다.

갱신:

```bash
python3 scripts/update_market.py       # data/market_history.json 재생성
```

`.github/workflows/update-market.yml`이 매일 한 번 자동 갱신합니다(선택).

## 계산식

입금 `(t_i, A_i)`에 대해

```
내 자산        V_now
지수 평가액    Σ_i  (A_i / FX(t_i)) / Index(t_i) × Index(now) × FX(now)
목표 연이율    Σ_i  A_i × (1 + r)^(years(t_i → now))
수익률         V_now / Σ A_i − 1,   연환산은 XIRR
```

18단계 구간은 `원금` → `최종 목표` 사이를 **기하급수 18등분**한 값입니다.
